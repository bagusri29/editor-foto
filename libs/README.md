# libs/ (opsional)

Aplikasi memuat Fabric.js dan glfx.js dari CDN. Untuk penggunaan produksi atau offline,
letakkan salinan lokal di folder ini; salinan lokal dicoba lebih dulu.

| Berkas | Sumber |
|---|---|
| `fabric.min.js` | Fabric.js 5.3.0 (build `dist/fabric.min.js`). Gunakan seri 5.x, bukan 6.x: API-nya berbeda. |
| `glfx.js` | `glfx.js` dari repositori evanw/glfx.js |
